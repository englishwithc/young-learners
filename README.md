# 🎓 Young Learners ESL Games Hub

A central navigation page for all games in this repository — designed to help teachers quickly find and access each game while keeping everything organized by category.

## 📁 What Is This?

This is a single-page index hub (`index.html`) that links to all the individual game folders in your `young-learners` repository. Each game lives in its own folder on GitHub Pages, but this page brings them together into one easy-to-browse interface.

## 🚀 How to Use It

1. **Navigate to this repo** on GitHub:  
   https://englishwithc.github.io/young-learners/

2. **Use the filter buttons** at the top to quickly jump between categories like Alphabet, Grammar, Body Parts, Colours, Numbers, Family, Shapes, and Listening.

3. **Click any game card** to see its description, a teacher tip, and a "Play Game" button that opens the game in a new tab.

4. **Want to track student progress?** Open the [Scoring System](https://englishwithc.github.io/useful-games/scoring-pirates-plunder/) in a second window or side-by-side with any game — it works alongside all games for leaderboards and point tracking!

## 🎨 Features

- ✅ Color-coded category bands on each card
- ✅ Emoji icons to quickly identify game purpose
- ✅ Expandable cards showing descriptions & teacher tips
- ✅ Filter buttons to sort by topic
- ✅ Responsive design (works on tablets and phones)
- ✅ No JavaScript files or external dependencies — everything is in one HTML file

## 🏴‍☠️ Bonus: Scoring System

The [Scoring Pirates Plunder](https://englishwithc.github.io/useful-games/scoring-pirates-plunder/) page provides a free points & leaderboard system that works with any game. Teachers can open both the hub and scoring system in separate windows for easy classroom use.
