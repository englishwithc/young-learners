🎙️ Your own recordings — the site automatically uses your audio files instead of the computer voice when they exist. Create a folder called audio next to this website file and record like this:
audio\letters\a.mp3 — pure letter sound (“aaah”, “buh”…)
audio\words\cv\ba.mp3 — 2-letter sound blend said as one pure sound (“b(ah)”)
audio\words\cvc\cat.mp3 — whole 3-letter word said naturally
audio\praise\great_job.mp3 — happy praise phrases
The full list of every file name to record is in Recording List.txt (next to this file). MP3 recommended.
